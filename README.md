## The entry

One word, the first that came to mind:

> **petrichor**

The smell of rain on dry earth. Nine letters that call up a whole
afternoon: dust, thunder, the first drops on hot ground. Vivid, specific,
surprising — not a safe filler word, and not a word anyone guesses first.

## The program

`main.ts` (Node 22, standard library only) writes that single word to
`/output/entry.txt`, inside the 1–24 character gate.
